# Ternary Machine

A hardware-independent computing platform based on a balanced-ternary virtual architecture.

## Status

Early development.

The project is currently in the requirements and architecture-definition phase.

## Project

The goal is to investigate and implement a complete computing environment consisting of:

- a balanced-ternary virtual machine architecture;
- a native ternary executable format;
- a ternary operating system;
- host-independent execution;
- host backends for different physical architectures;
- and, eventually, translation between conventional binary software and the ternary execution environment.

The architecture and implementation are being developed incrementally and will be specified before major implementation work begins.
